DM Screen app
=============

Goals
-----

### Selling line

"A tablet-first app to make DMing DnD games easy."

### Specific goals

- DMs (and players) must be able to start off games anytime, and almost effortlessy. If this app does not make it significantly easier and more enticing to play DnD as compared to doing so using pencil and paper, this project has unequivocally FAILED.

- Almost implied in the above: DMs and players must be able to start games without first defining every detail about their characters, the plot or the setting. It must be possible to leave almost everything undefined until such time that a given piece of information (such as an ability score, a skill, or a saving throw) becomes necessary to determine the outcome of a situation. The app must then make it easy to add the required information before returning to the calculation (or even just the display, if the DM elects to take the decision by himself).

### Non-goals


### Anti-goals

- Though a future version might interface with AI (that option might even become a distinctive feature of a non-free "deluxe" version), this app must explicitly be able to run completely without the help of AI. Thus, it must make every effort to allow the DM to input his ideas with as little hassle as possible, particulary regarding calculations and the inputting of text.


### Notes on implementation

- Reflecting the general goal of letting DMs and players "make things up as they go", the app owns the responsibility to clearly indicate to the user when and where a piece of information has yet to be defined.
